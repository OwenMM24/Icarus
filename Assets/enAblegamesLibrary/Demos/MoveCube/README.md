# Move Cube Demo

## Instruction
This demo will showcase you simple usage of basic functions in EGDL you will need to make the your game:
- Using SUKI to gain access of different inputs
- Using parameter system so you can sync your parameter in the script with main menu and being able to override it from portal
- Using tracker system so you can record messages and send it to portal

To run or build the demo, add these scenes to the build settings with the correct **scene index**:
0. eag_Login eag_MainMenu
1. eag_MoveCubeGame
2. eag_KickCubeGame
